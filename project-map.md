# Mapa del proyecto

- Proyecto: SENTIDA Pastelería
- Tipo: reconstrucción
- Resultado: implementación y handoff
- Fuente de verdad: `web referencia.jpeg`, logo SVG, paleta SVG y banco `SENTIDA-recursos-web(1).zip`
- Nivel: réplica funcional
- Viewport de referencia: 1055 × 1491 px
- Acción principal: explorar catálogo; secundaria: iniciar pedido por WhatsApp
- Tecnología: HTML, CSS y JavaScript sin framework

## Decisiones

- Fijas: orden de secciones, relación foto/texto, paleta, escala editorial, ritmo suave, composición panorámica.
- Inferidas: menú colapsable, carrusel táctil de favoritos, foco visible y desplazamiento suave.
- Pendientes: número de WhatsApp, destinos de redes y textos legales.
- Mobile: hero vertical; productos horizontales; celebraciones e historia apiladas; CTA condensado.
- Movimiento: respuesta sutil al hover y scroll suave; se desactiva con `prefers-reduced-motion`.
